### Контраст (WCAG AA) — почему три оранжевых

`#E67E22` с белым текстом даёт 2.85:1, а как цвет текста на `#F8F6F2` — 2.64:1: это ниже порога
WCAG AA (4.5:1), Lighthouse снижает Accessibility. Поэтому (решение 2026-09-28):

- `#E67E22` остаётся фирменным, но только для **нетекстовых** элементов;
- всё, что **читается** оранжевым (цены, депозит), — `#A95A0E`;
- кнопки с белым текстом (CTA «Скачать», «Забронировать», «Разместить», FAB) — фон `#AE6217`, hover `#9B5714`.

> В задаче предлагались `#B8620F` / `#C46E1A`, но фактический контраст у них 4.06:1 на фоне
> и 3.76:1 с белым — AA не проходят. Взяты ближайшие оттенки того же тона, которые проходят с запасом.

### Строжайшие запреты по цвету

- ❌ Никаких градиентов
- ❌ Никакого тёмного фона (dark mode не предусмотрен)
- ❌ Никакого чисто белого `#FFFFFF` фона экранов — только `#F8F6F2`
- ❌ Никаких других оранжевых кроме `#E67E22` и его тёмных вариантов для текста/кнопок (`#A95A0E`, `#AE6217`, `#9B5714`)
- ❌ Никаких других синих кроме `#1A5276`

## 🖼️ Логотип — точное описание

```
Символ:
- Ключ (белый) внутри синего круга #1A5276
- Вокруг круга: две стрелки обмена (оранжевые #E67E22)
  верхняя стрелка → вправо вверх
  нижняя стрелка → влево вниз
- Итого: символ «ключ + обмен» = доступ + передача

Wordmark:
- «KIROYA» — ExtraBold геометрический sans-serif
- Цвет: #1A5276 (на светлом) / #FFFFFF (на тёмном синем фоне)
- Буква Y: оранжевая точка #E67E22 в нижней точке Y
- Подпись: «Арендуй. Доверяй. Зарабатывай.» 13px regular #6B7280

Версии:
1. Горизонтальная: символ + wordmark справа
2. Вертикальная: символ сверху + wordmark снизу
3. Только символ: для favicon, аватара, AppIcon
4. На тёмном: весь белый + оранжевые стрелки

App Icon:
- Фон: #1A5276
- Символ: белый ключ + оранжевые стрелки
- border-radius: 22.5% (iOS стандарт)
```
